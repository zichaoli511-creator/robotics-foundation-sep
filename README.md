# Robotics Foundation September

## 项目目标

恢复 Linux、C++、Python 和 Git 基础，学习 CMake 与 Eigen，为后续 ROS2 Humble、机械臂运动学和运动规划打下基础。

## 当前开发环境

- Windows 11
- WSL 2
- Ubuntu 22.04 LTS
- GCC/G++ 11.4
- CMake 3.22.1
- Git 2.34.1
- Python 3.10.12
- Eigen 3

## 2026 年 9 月验收目标

- 熟悉常用 Linux 命令
- 能够使用 Git 记录代码修改
- 能够创建并编译一个 CMake C++ 项目
- 能够使用 Eigen 完成基本矩阵运算
- 能够使用 Python、NumPy 和 Matplotlib 处理及绘制轨迹数据
- 完成一个可以独立构建运行的 GitHub 项目
